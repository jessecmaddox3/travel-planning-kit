# Rental research

> **TL;DR:** Compare like-for-like dates and full stay totals, preserve evidence, and explain the ranking. Put actual research in your private trip folder.

Start with the trip brief. Define the search area, maximum drive, required sleeping arrangement, must-have amenities and budget scope. Record the date you checked each source.

For every candidate, gather all 22 comparison fields in the kit: name, platform, source URL, area, drive, sleeps, bedrooms, bathrooms, square feet, acreage, theater, waterfront, pool, hot tub, game room, other amenities, quoted total, household split, rating, cancellation, availability and notes. Add the actual bed layout, practical details for children if relevant, sauna status and photos you may use.

Quote the exact arrival/departure dates and state whether fees and taxes are included. Use `exact` only for an actual total, `range` for an estimate with explicit bounds, and `unknown` when absent. Never convert a nightly teaser into a full stay total without checking the basis. Mark ambiguous amenities and availability as unknown.

Keep a shortlist, alternatives and rejected candidates. Each gets a short reason. A rejection should explain a concrete mismatch, so the same listing does not get researched repeatedly. Preserve source links and caveats in the final comparison.

If using an assistant, ask it to separate verified facts from inference, supply exact source links and dates, and stop before bookings, messages or paid actions. Review the result before importing it.
