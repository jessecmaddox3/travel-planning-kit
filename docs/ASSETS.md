# Asset notes

> **TL;DR:** All three shipped illustrations were generated for this public kit. They depict invented scenes and properties. No real trip photos or rental listing assets are included.

The README illustration is `docs/travel-planning-kit-hero.png`. The two fictional property images are `travel_kit/example/images/fictional-cottage.png` and `fictional-cabin.png`. Their prompts are retained in this folder. They were generated with ChatGPT's image generation tool and are original outputs prepared for this project. No reference image from a real trip was supplied.

The example may reuse an illustration in more than one photo position to demonstrate a gallery. It is illustrative content, not evidence about a real property. No image is a real listing recommendation.

The project makes these generated outputs available under the same permissive terms as the kit, to the extent the author can grant them. It makes no claim of exclusive rights in generated content. Local system font stacks require no bundled font files. The runtime has no third-party Python or JavaScript packages. Development tools are not vendored.

Photos and text you add from third parties keep their own rights. The photo-fetching helper does not change those rights.
